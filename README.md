# Job Application Tracker

A simple web-based application that helps users manage and track their job applications in one place.

The application allows users to create an account, add job applications, update application status, search and filter applications, and monitor their overall application progress.

---

## Features

- User Registration and Login
- Secure session-based authentication
- Add new job applications
- Edit existing applications
- Delete applications
- Track application status
- Search applications by company, role, or location
- Filter applications by status
- View application statistics
- Add notes for each application
- Store job posting URLs
- User-specific application data
- MySQL database integration
- Simple and responsive user interface

---

## Application Status

The tracker supports the following application statuses:

- Applied
- Under Review
- Shortlisted
- Interview
- Selected
- Rejected
- Withdrawn
